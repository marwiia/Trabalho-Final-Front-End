# Trabalho-Final-Front-End
Projeto final de Front-End

Sobre o projeto

A OCEAN Entertainment é uma empresa fictícia de entretenimento criada como projeto acadêmico para a disciplina de Desenvolvimento Web Front-End.

Inspirada no universo da indústria musical, a proposta do site é apresentar uma empresa voltada ao desenvolvimento de artistas, projetos musicais e divulgação de lançamentos.

A identidade visual utiliza tons de azul, branco e cinza, buscando transmitir criatividade, modernidade e conexão com a música.

Objetivo

Desenvolver um site institucional simples e organizado, utilizando HTML e CSS, para apresentar a empresa, seus artistas, lançamentos e principais informações.

Tecnologias utilizadas

HTML5: estruturação das páginas e organização dos conteúdos.

CSS3: estilização, cores, fontes, espaçamentos e organização visual.
